# Music Player

Web music player giao diện desktop lấy cảm hứng từ các trình phát nhạc hiện đại.

## Tính năng
- Import nhiều file audio từ máy tính.
- Phát / tạm dừng / bài trước / bài tiếp theo.
- Thanh tiến trình và âm lượng.
- Shuffle và repeat.
- Tìm kiếm bài hát, nghệ sĩ, album.
- Danh sách yêu thích và phát gần đây.
- Giao diện responsive cho màn hình nhỏ.

## Chạy trên GitHub Pages
